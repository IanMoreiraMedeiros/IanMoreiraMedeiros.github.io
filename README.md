# Portfólio pessoal de Ian Lucas

Site de portfólio pessoal desenvolvido para apresentar quem sou, meus interesses, minha trajetória, minha formação acadêmica e minhas experiências profissionais.

## Projeto em produção

[Acessar o portfólio](https://ian-lucas-portfolio-2026.command-syst-1786.chatgpt.site)

## Sobre o desafio

Este projeto foi criado para o desafio Front-End: Desenvolva seu portfólio pessoal.

O objetivo do desafio é construir um site de portfólio pessoal responsivo e funcional, que sirva para apresentar quem você é, seus interesses e sua trajetória.

## Requisitos obrigatórios

### 1. Sobre mim

O site contém um resumo sobre Ian Lucas Moreira Medeiros, estudante de Ciência da Computação na Universidade Federal do Ceará, campus de Russas, desenvolvedor full-stack e designer.

### 2. Hobbies

A seção de hobbies apresenta jogos, corrida, musculação, basquete, vôlei e futsal. Ela utiliza elementos flutuantes, emojis, uma fotografia em órbita e interações criadas com GSAP.

### 3. Formação acadêmica

A formação apresenta a graduação em Ciência da Computação na Universidade Federal do Ceará, iniciada em 2024.1 e atualmente no 6º semestre.

Também são exibidos os certificados de participação na organização da VIII Semana de Engenharia de Software e Ciência da Computação e de atuação na Diretoria de Marketing do Centro Acadêmico Ada Lovelace.

### 4. Experiências profissionais e projetos

O portfólio apresenta as seguintes experiências:

- Estágio como desenvolvedor full-stack na CommandSystem.
- Participação no Projeto de Pesquisa ARES como designer e idealista de conteúdo.
- Atuação no Centro Acadêmico Ada Lovelace como designer e gestor de mídias.
- Participação na organização de salas temáticas da SESCOMP.

## Diferenciais implementados

- Design responsivo para celular e desktop.
- Animações de entrada, paralaxe, órbita e rolagem horizontal.
- Linha do tempo interativa criada com GSAP e ScrollTrigger.
- Controles por rolagem, toque, teclado e botões de navegação.
- Suporte aos temas claro e escuro.
- Preferência de tema salva no navegador.
- Suporte à configuração de redução de movimento do sistema.
- Certificados disponíveis para visualização em PDF.

## Como executar localmente

É necessário ter o Node.js instalado.

```bash
npm install
npm run dev
```

Depois, acesse `http://localhost:3000` no navegador.

## Como gerar a versão de produção

```bash
npm run build
```

## Organização do código

- `app/page.tsx`: conteúdo, componentes da página e animações GSAP.
- `app/globals.css`: identidade visual, responsividade, temas e estados interativos.
- `app/layout.tsx`: metadados, fontes e configuração geral da página.
- `public`: fotografias, certificados e imagem de compartilhamento.

## Evolução do projeto
