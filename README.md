# Portfólio — Ian Lucas

Portfólio pessoal desenvolvido para apresentar minha trajetória, formação, interesses e experiências em desenvolvimento e design.

## Destaques

- Abertura responsiva com fotografia autoral e navegação por seções.
- Linha do tempo horizontal animada com GSAP e ScrollTrigger.
- Interações por mouse, teclado, toque e rolagem.
- Seção dinâmica de hobbies com elementos em órbita.
- Formação acadêmica, espaço para certificações e experiências profissionais.
- Tema claro/escuro com preferência salva no navegador.
- Respeito à configuração de redução de movimento do sistema.

## Tecnologias

- React 19
- TypeScript
- GSAP + ScrollTrigger
- Vinext / Vite
- Tailwind CSS
- Componentes shadcn e ícones Lucide

## Executando localmente

```bash
npm install
npm run dev
```

Depois, abra `http://localhost:3000`.

Para gerar a versão de produção:

```bash
npm run build
```
